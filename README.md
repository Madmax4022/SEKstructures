# SEK Estructuras

Herramienta independiente para la ejecución de **inspecciones** y la **gestión legal/logística de hallazgos**. Producto propiedad de su creador.

**Filosofía:** 80/20, *menos es más* y **norma abierta**. El núcleo es siempre el mismo: detectar un hallazgo → asignarle un nivel de riesgo (1–5) → cerrarlo con evidencia trazable. La norma valida donde aplica, pero un hallazgo **no necesita una norma para existir**: también entran los riesgos emergentes no normados.
